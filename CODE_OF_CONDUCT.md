# Code of Conduct

We are committed to a welcoming, respectful and harassment-free community.

Expected behavior: be considerate, constructive, patient and respectful of differing viewpoints. Discuss code and ideas, not people.

Harassment, discrimination, personal attacks, threats, doxxing and publishing private information without consent are not acceptable.

Maintainers may remove content or restrict participation for behavior that violates this code. Report safety concerns privately to the repository maintainers.
