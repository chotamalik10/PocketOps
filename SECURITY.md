# Security Policy

## Supported versions
Security fixes target the latest development version.

## Reporting a vulnerability
Please do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting / security advisory feature for this repository. Include the affected version, reproduction steps and impact.

## Data safety
PocketOps stores data locally in the browser. This does not protect data on a compromised device or browser profile. Do not store passwords, payment-card details or highly sensitive identity data. Export backups regularly and protect your device account.
